# Team Task Manager

A production-style full-stack MERN application for managing projects and tasks with authentication and role-based access control.

---

## Features

- JWT Authentication
- Role-Based Access Control (Admin / Member)
- Project Management
- Task Assignment & Tracking
- Dashboard Analytics
- Protected Routes
- Responsive Modern UI
- Toast Notifications
- Full Deployment

---

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- React Router DOM
- React Hot Toast

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs
